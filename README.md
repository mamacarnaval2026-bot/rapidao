# Portal Sim Empresas

Landing page responsiva de consultoria empresarial.

## Arquivos
- index.html
- style.css
- script.js

## Antes de publicar
Abra `script.js` e altere:
`const whatsapp = "5500000000000";`

Coloque o número de WhatsApp da empresa no formato internacional, somente números.

## Publicação
Pode ser publicada diretamente no GitHub Pages, Netlify ou Vercel.
